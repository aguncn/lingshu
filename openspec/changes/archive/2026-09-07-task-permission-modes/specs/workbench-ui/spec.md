## MODIFIED Requirements

### Requirement: 可折叠细节栏与任务模型绑定

系统 SHALL 在右栏底部提供默认收起的可折叠细节栏，可展开/收起。选中任务绑定了场景域（`scenario_domain` 非空且清单可译出名称）时，开关行与展开体顶部 SHALL 显示该域名称标记并注明「已按该域预设装配；增删改请用各分区编辑挂载」，未绑域不显示该标记。展开后 SHALL 分区呈现「模型 / 工作空间 / 技能 / MCP / 知识库 / 专家 / 资料 / 权限模式」：模型分区实连 `GET /api/model-providers` 与 `GET/POST/PATCH /api/tasks/<task_id>/model-config`，支持查看供应商（掩码密钥展示）与为当前任务绑定模型/调参（`temperature`、`max_tokens`、`timeout`）；工作空间分区显示任务所属空间信息。技能、MCP、知识库、专家四类 SHALL 各自以独立分区经 `GET/PUT /api/tasks/<task_id>/caps` 读取并全量覆盖装配当前任务的真实挂载（AgentScope 技能 / 外部 MCP 连接器 / 知识库 / 专家）：同类的多个挂载以标签逐行呈现，停用或未就绪实体以弱化态标注（如「· 停用」）且不阻断显示；某类无任何挂载时 SHALL 显示该类稳定空态文案（如「未挂载技能」）；四类分区 SHALL 共用同一全量覆盖式编辑器，避免单类改动清空其余挂载。资料分区在 P6 已交付时 SHALL 展示任务已引用的集中资料库文件（文件树 kind=ref 行）并提供添加/解除引用；解除引用只删关联、不删库文件。权限模式分区 SHALL 实连任务 `permission_mode`（`PATCH /api/tasks/<id>`）：以三档「严格 / 有限 / 完全信任」即时切换并持久化，成功后提示「下次提问生效」；切换 SHALL 不打断当前正在运行的会话，只作用于该任务之后新发起的 run。

#### Scenario: 细节栏默认收起且可展开收起

- **WHEN** 用户进入任一任务视图，点击细节栏的展开/收起控件
- **THEN** 细节栏初始为收起态，点击后可展开显示各分区，再次点击恢复收起，状态不与其他任务串扰

#### Scenario: 模型分区绑定与调参经真实接口生效

- **WHEN** 用户在模型分区选择一个已存在的供应商（来自 `/api/model-providers`）为当前任务绑定，并调整 `temperature`/`max_tokens`/`timeout`
- **THEN** 绑定与调参写入该任务的 `model-config`（POST 首次 201 / PATCH 调参 200），细节栏回显掩码密钥与最新参数；重新进入后仍一致

#### Scenario: 技能/MCP/资料分区展示真实挂载与库引用

- **WHEN** 选中一个已通过 `PUT /api/tasks/<id>/caps` 装配了技能、MCP、知识库与专家的任务，展开细节栏查看「技能 / MCP / 知识库 / 专家」分区
- **THEN** 四类各自独立列出该任务当前挂载项（含停用/未就绪弱化标记，名称经注册中心/域清单译为可读名），任一分区「编辑挂载」打开全量覆盖式编辑器（含知识库/专家挂载）且不因单类改动清空其余挂载；资料分区列出已引用的库文件并可添加/解除引用，解除引用后该行从任务文件树消失、集中库文件本体不受影响

#### Scenario: 场景域绑定任务的装配在细节栏一眼可见

- **WHEN** 选中一个经建任务选域/顶部域条自动套用了场景域预设的任务并展开细节栏
- **THEN** 开关行与展开体顶部显示该域名称标记与「已按该域预设装配」说明；四类挂载分区列出该域预设成功挂载的实体（如故障诊断 = 监控/日志/链路三 MCP 连接器 + SRE 专家）

#### Scenario: 细节栏调整权限模式即时持久化

- **WHEN** 用户在「权限模式」分区把某任务从默认「严格」切换为「有限」或「完全信任」
- **THEN** 该任务经 `PATCH /api/tasks/<id>` 持久化为所选档位，分区标签即时更新并提示「下次提问生效」；刷新/重进后仍为该档；当前正在运行的会话不被中断，新发起对话按新档装配

#### Scenario: 未交付能力分区为空态占位

- **WHEN** 选中任务某类能力无任何挂载
- **THEN** 对应分区显示稳定的空态占位与说明（如「未挂载技能」「未挂载 MCP」「未挂载知识库」「未挂载专家」），展开/收起与切任务均不报错

## ADDED Requirements

### Requirement: 新建任务对话框的任务权限模式选择

系统 SHALL 在新建任务对话框提供「权限模式」三档选择（取值 `strict`/`limited`/`trusted`）：`严格`（所有写/执行类工具都确认，安全但频繁打断，默认）、`有限`（只读与一般命令自动放行，仅删除/覆盖命令与修改本地文件 Write/Edit 时确认一次）、`完全信任`（全程无人工确认，模型按系统提示约束自我把关）。所选值 SHALL 随 `POST /api/spaces/<sid>/tasks` 一并提交并写入任务。对话框每次打开 SHALL 回默认 `strict`（用户按任务风险显式下调），不残留上一次选择的档位。

#### Scenario: 建任务按所选档位创建

- **WHEN** 用户在新建任务对话框把权限模式选为「有限」/「完全信任」并提交成功
- **THEN** 新任务创建成功且其 `permission_mode` 为该档（任务详情/细节栏可见）；随后再次打开新建对话框默认回到「严格」

#### Scenario: 不改动即默认严格

- **WHEN** 用户在新建任务对话框保留权限模式默认值直接提交
- **THEN** 新任务 `permission_mode='strict'`（与既有默认确认行为一致）
